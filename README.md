## 得分策略

题面满分120分。优先完成抛投任务60分、真实位置与状态地面站15分、设计报告20分，再争取动态起降20分及细则待定的其他5分。前三项合计95分是目标模块上限，不能视为已经获得的分数。

小车每次任务必须连续行进一圈，途中不得停车，整圈不超过90秒；否则对应模块不得分。无人机轴距不超过45cm，桨叶必须全防护。

## 四天检查点

| 时间 | 阶段结果 |
| --- | --- |
| 第一天，T+24h | 带载循线、无线启动、自动起降与真实遥测可用 |
| 第二天，T+48h | B前伴飞、D前投放、无人机回H、小车回A，完整流程不超过90秒 |
| 第三天，T+66h | 验证移动平台起降；不稳定则停止扩展，保留稳定抛投版本 |
| 第四天，T+84h | 重复成功率验收、离线模拟测评、报告与材料完成 |

采购到货、初步装机和满载基础试飞应在84小时计时前完成。低预算优先借用学校已调通的自主无人机、笔记本和工具。
